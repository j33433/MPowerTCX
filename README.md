# MPowerTCX

Convert CSV files from indoor cycling bikes to TCX format for Strava, Garmin
Connect, TrainingPeaks, and Golden Cheetah. All processing runs in the browser
via WebAssembly, no server needed.

Try it at [upload.bike](https://upload.bike).

## Supported equipment

- Schwinn MPower Echelon (3 firmware variants)
- Stages Indoor Cycles
- The Sufferfest
- Wahoo SYSTM
- NordicTrack Studio Cycles
- PRO-FORM iFit

Don't see your bike? Email your CSV to upload.bike@gmail.com.

## CLI usage

```
cargo run -- --csv input.csv --tcx output.tcx
```

Options:
- `--csv <FILE>` - input CSV file (required)
- `--tcx <FILE>` - output TCX file (required)
- `--time <TIME>` - workout start time (defaults to file timestamp)
- `--interpolate` - resample to 1-second intervals (recommended)
- `--model <MASS_KG>` - use physics model for speed and distance

## Web version

The static site in `web/` runs entirely client-side. To preview locally:

```
cd web && python3 -m http.server
```

Then open http://localhost:8000.

### Rebuild the WASM package

```
wasm-pack build crates/mpowertcx-wasm --target web --out-dir ../../web/pkg
```

## Desktop app

A Tauri wrapper around the web frontend, packaged as a standalone desktop
app for Windows, macOS, and Linux. The download page at
[upload.bike/download.html](https://upload.bike/download.html) links to
installers hosted in `web/downloads/`.

### Prerequisites

- [Rust](https://www.rust-lang.org/tools/install)
- [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/)
- [Tauri prerequisites](https://tauri.app/start/prerequisites/) (system libs per platform)

### Build installers

Install the Tauri CLI:

```
cargo install tauri-cli --version "^2"
```

Build the WASM package and desktop app:

```
wasm-pack build crates/mpowertcx-wasm --target web --out-dir ../../web/pkg
cargo tauri build
```

Installers are written to `src-tauri/target/release/bundle/`. Copy them
to `web/downloads/` with these names so the download page picks them up:

| Platform | Filename |
|----------|----------|
| Windows | `upload.bike-windows.msi` |
| macOS (Apple Silicon) | `upload.bike-macos-arm64.dmg` |
| macOS (Intel) | `upload.bike-macos-x64.dmg` |
| Linux | `upload.bike-linux.AppImage` |

### CI builds

A GitHub Actions workflow (`.github/workflows/build-desktop.yml`) builds
all four platforms in parallel. Push a tag like `v2.2.0` to trigger it:

```
git tag v2.2.0
git push origin v2.2.0
```

The workflow creates a GitHub Release with all installers attached.
Download them and copy to `web/downloads/`. You can also run it manually
from the Actions tab (workflow_dispatch) to get artifacts without a release.

### Dev mode

```
cargo tauri dev
```

### Build from source

```
git clone https://github.com/clanken/MPowerTCX.git
cd MPowerTCX
wasm-pack build crates/mpowertcx-wasm --target web --out-dir ../../web/pkg
cargo tauri build
```

## Tests

Integration tests compare output against 25 sample files in `samples/`:

```
cargo test -p mpowertcx-core
```

Shell scripts for byte-exact comparison of plain and model outputs:

```
bash test_samples.sh
bash test_samples_advanced.sh
```

## Project structure

```
crates/
  mpowertcx-core/     conversion library (no I/O, WASM-compatible)
  mpowertcx-cli/      command-line binary
  mpowertcx-wasm/     WebAssembly build for the web frontend
src-tauri/            Tauri desktop app (wraps web/ in a native window)
web/
  index.html          converter page
  how-it-works.html   explanatory page with interactive graph
  download.html       desktop app and CLI downloads page
  custom.css          shared styles (Pico CSS + custom)
  chart-demo.js       physics model chart engine (ES module)
  pkg/                WASM package (generated by wasm-pack)
  downloads/          built desktop installers (gitignored)
  samples/            sample CSV for the graph demo
samples/              test CSVs and expected TCX outputs
legacy/               original Python/PySide2 desktop app (unmaintained)
```
