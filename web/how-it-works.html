How It Works

upload.bike converts CSV files from indoor cycling bikes into TCX format for Strava, Garmin Connect, TrainingPeaks, and Golden Cheetah. Here's what's going on, and why your bike's numbers might not match Strava.

What is a TCX file?

TCX (Training Center XML) is a Garmin file format for workout data. It's an XML file with a time series of power, heart rate, cadence, speed, and distance, typically one data point per second.

Strava, Garmin Connect, TrainingPeaks, and Golden Cheetah all accept TCX uploads. But indoor bikes don't produce TCX. They produce CSV files: plain text with columns for power, cadence, heart rate, and distance. These platforms won't take CSV. upload.bike reads the CSV and writes a TCX file they'll accept.

The Physics Model: Fixing Bad Speed and Distance

Many indoor bikes estimate speed and distance from wheel RPM or resistance level instead of measuring it. The result can be noticeably wrong. When you upload that to Strava, your ride shows the wrong distance, wrong speed, wrong calories.

The physics model ignores the bike's speed and distance. Instead it takes your actual power output (watts) and your combined mass (rider + bike), then calculates speed using the same forces that govern outdoor cycling:

  • Aerodynamic drag: 0.5 x Cd x frontal area x air density x v^2
  • Rolling resistance: mg x Crr x cos(theta)
  • Drivetrain efficiency: 97% power transfer

At each time step, the model solves: given the power you produced and the resistive forces at your current speed, what's your new speed? Distance accumulates from speed over time.

Fix Timing: Interpolation for Compatibility

Some indoor bikes record data every 3, 5, or 10 seconds instead of every second. That's fine for the bike's display, but fitness platforms like Strava and Garmin Connect expect 1-second intervals in TCX files. Gaps can cause:

  • Wrong total duration in Strava
  • Missing data in analysis charts
  • Segment matching and relative effort problems
  • Import errors on some platforms

The Fix Timing option (on by default) resamples your data to 1-second intervals using cubic spline interpolation. If you were doing 200W at second 0 and 210W at second 5, it fills in reasonable values for seconds 1 through 4. The result is a TCX file with clean, continuous data that imports without issues.

The interpolation uses not-a-knot cubic spline boundary conditions, same as SciPy's splrep/splev. The conversion engine is written in Rust and compiled to WebAssembly, so it all runs in your browser.

Getting Your CSV File

Schwinn MPower Echelon

  1. Insert a USB thumb drive into the slot at the top of the console
  2. Do your workout
  3. Stop pedalling
  4. Press and hold AVG/MAX for 5 seconds
  5. Wait for the flashing USB logo to stop, then remove the drive
  6. The drive contains a file named something like MPower12.csv

Stages Indoor Cycles

  1. From the console, go to the ride summary or history
  2. Insert a USB drive and select the export option
  3. The file saves with a name like STAGES01.csv

Stages SIC1 Console Quick Start Tutorial (video) | Stages Firmware and Manuals

The Sufferfest & Wahoo SYSTM

These apps can export workout data as CSV. Look for the export option in the app's workout history or activity settings. The exported file has columns for power, cadence, heart rate, and speed.

USB drive problems? Some Schwinn consoles crash with newer USB thumb drives. A 1GB drive is your best bet. If the USB logo fails to flash at the end of a ride or the unit shuts off, the drive is probably incompatible.

Converting and Uploading

  1. Go to upload.bike
  2. Click Choose CSV file and select your exported file
  3. Enable Fix Timing (recommended) for 1-second interpolation
  4. Enable Fix speed and distance if your bike's distance seems off, and enter your combined rider + bike weight
  5. Click Download TCX
  6. Upload the TCX file to your platform:
  • Strava upload
  • Garmin Connect import
  • TrainingPeaks: "Upload Activity" button
  • Golden Cheetah: File > Import Activity

FAQ

Why is my distance different after conversion?

Many indoor bikes estimate distance from wheel RPM or resistance, which can be off by 10% or more. The physics model recalculates distance from your actual power output, rider mass, and physical constants, giving a more realistic number.

What if my bike isn't in the supported list?

Email your CSV to upload.bike@gmail.com. The tool supports Schwinn MPower Echelon (3 firmware variants), Stages, The Sufferfest, Wahoo SYSTM, and others. New formats can usually be added if you provide a sample file.

Is my data sent to a server?

No. All conversion runs in your browser via WebAssembly. Your data never leaves your device.

Why does the physics model need my weight?

Mass affects speed for a given power output. A heavier rider goes slower at the same wattage on flat ground (more rolling resistance). The model uses combined rider + bike mass to solve the equations of motion.

What CSV formats are supported?

Schwinn MPower Echelon (3 variants), Stages Indoor Cycles (metric and English, with or without headers), The Sufferfest, Wahoo SYSTM, and several NordicTrack and PRO-FORM iFit variants. If your file has power, cadence, heart rate, and distance columns, it can probably be supported.

Why does Strava show a different time than my bike console?

Some bikes record every 3 or 5 seconds instead of every second. Fix Timing resamples to 1-second intervals using cubic spline interpolation, so the duration matches what fitness platforms expect.

The USB export didn't work on my Schwinn bike. What do I do?

Some consoles crash with newer USB thumb drives. A 1GB drive works best. If the USB logo fails to flash or the unit shuts off during export, try an older, smaller drive.

Can I adjust the power readings?

Yes. Power meters on indoor bikes can vary 5-10% between units. The power adjustment setting (in the CLI) applies a percentage correction. Set it to -5 if your bike reads 5% high, +5 if it reads low.

Troubleshooting

USB drive not working

Schwinn MPower consoles can be picky about USB drives. Newer high-capacity drives may crash the console or fail to export. Try a small, older drive. 1GB is ideal. If the USB logo fails to flash or the console shuts off during export, the drive is incompatible.

File won't load

Different bike models and firmware versions produce different CSV formats. If your file doesn't load, email it to upload.bike@gmail.com and I'll add support for it.

Distance looks wrong in Strava

Enable Fix speed and distance and enter your weight. This replaces the bike's distance estimate with a physics-based calculation from your power output. See the physics model section above.
