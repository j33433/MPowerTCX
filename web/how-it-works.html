How It Works

upload.bike converts CSV files from indoor bikes into TCX format for Strava, Garmin Connect, TrainingPeaks, and Golden Cheetah.

What is a TCX file?

TCX (Training Center XML) is a Garmin file format for workout data. It contains a time series of power, heart rate, cadence, speed, and distance, usually one point per second.

Strava, Garmin Connect, TrainingPeaks, and Golden Cheetah all accept TCX uploads. Indoor bikes don't produce TCX though. They produce CSV files: plain text with columns for power, cadence, heart rate, and distance. These platforms won't take CSV. upload.bike reads the CSV and writes a TCX file they'll accept.

The Physics Model: Fixing Bad Speed and Distance

Many indoor bikes estimate speed and distance from wheel RPM or resistance level instead of measuring it. That can be off by quite a bit. When you upload that to Strava, your ride shows the wrong distance, speed, and calories.

The physics model ignores the bike's speed and distance. Instead it takes your actual power output (watts) and your combined mass (rider + bike), then calculates speed using the same forces that govern outdoor cycling:

  • Aerodynamic drag: ½ × Cd × A × ρ × v²
  • Rolling resistance: mg × Crr × cos(θ)
  • Drivetrain efficiency: 97% power transfer

At each time step, the model solves: given the power you produced and the resistive forces at your current speed, what's your new speed? Distance accumulates from speed over time.

Fix Timing: Interpolation for Compatibility

Some indoor bikes record data every 3, 5, or 10 seconds instead of every second. That's fine for the bike's display, but fitness platforms like Strava and Garmin Connect expect 1-second intervals in TCX files. Gaps can cause wrong duration, missing data in analysis charts, segment matching problems, or import errors.

The Fix Timing option (on by default) resamples your data to 1-second intervals using cubic spline interpolation. If you were doing 200W at second 0 and 210W at second 5, it fills in reasonable values for seconds 1 through 4. The result is a TCX file with clean, continuous data that imports without issues.

Getting Your CSV File

Schwinn MPower Echelon

  1. Insert a USB thumb drive into the slot at the top of the console
  2. Do your workout
  3. Stop pedalling
  4. Press and hold AVG/MAX for 5 seconds
  5. Wait for the flashing USB logo to stop, then remove the drive
  6. The drive contains a file named something like MPower12.csv

Stages Indoor Cycles

  2. Insert a USB drive and select the export option
  3. The file saves with a name like STAGES01.csv

Stages SIC1 Console Quick Start Tutorial (video)

The Sufferfest & Wahoo SYSTM

These apps can export workout data as CSV. Look for the export option in the app's workout history or activity settings.

USB drive problems? Some Schwinn consoles crash with newer USB thumb drives. A 1GB drive is your best bet. If the USB logo fails to flash or the unit shuts off, the drive is probably incompatible.

Converting and Uploading

  1. Go to upload.bike
  2. Click Choose CSV file and select your exported file
  3. Enable Fix Timing (recommended) for 1-second interpolation
  4. Enable Fix speed and distance if your bike's distance seems off, and enter your combined rider + bike weight
  5. Click Download TCX
  6. Upload the TCX file to your platform:
  • Strava upload
  • Garmin Connect import
  • TrainingPeaks: "Upload Activity" button
  • Golden Cheetah: File > Import Activity

FAQ

Troubleshooting

File won't load

Different bike models and firmware versions produce different CSV formats. If your file doesn't load, email it to upload.bike@gmail.com and I'll add support for it.

Distance looks wrong in Strava

Enable Fix speed and distance and enter your weight. This replaces the bike's distance estimate with a physics-based calculation from your power output. See the physics model section above.
